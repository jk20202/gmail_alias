Gmail 绑定采用 Device Code 授权，只需要在下方填写一次 Google Cloud 的 OAuth 客户端凭据， 不需要配置任何回调地址。保存后立即生效，优先级高于 Worker 环境变量。

凭据加密存储，页面只回显脱敏后的 Client ID
如何获取？点击展开步骤
  1. 打开 Google Cloud 控制台 → API 和服务 → 凭据
  2. 配置「OAuth 同意屏幕」：用户类型选外部，填写应用名称与支持邮箱，测试用户里加上你自己的 Gmail
  3. 创建凭据 → OAuth 客户端 ID → 应用类型选桌面应用（不要选 Web 应用）
  4. 复制生成的 Client ID 与 Client Secret，粘贴到上方保存
  5. 回到「我的账户 → 绑定 Gmail」即可用授权码完成绑定
